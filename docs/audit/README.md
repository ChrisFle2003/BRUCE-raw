# Audits

Audits record a dated assessment of a particular working tree or acceptance
state. They support review and traceability, but they are historical snapshots
rather than evidence about the current checkout.

- [Repository analysis and next steps — 2026-10-06](2026-10-06-repository-analysis-and-next-steps.md)

For current claims, begin with the [documentation map](../README.md),
[Blueprint](../architecture/03-blueprint-consolidation.md), and current source
and tests. References to a semantic index concern a previous experiment; its
reversible local archive is `runs/retired-semantic-index/`, which is not an
active build component.
