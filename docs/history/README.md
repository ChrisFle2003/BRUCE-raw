# History

This directory and [HISTORY.md](../../HISTORY.md) preserve earlier repository
entry points and prior states. They support traceability, not present-tense
implementation claims.

For the current repository, begin with the [documentation map](../README.md),
the [Blueprint](../architecture/03-blueprint-consolidation.md), and the
[control and publication contract](../contracts/06-control-and-publication.md).
When using a historical file, retain its date, revision scope, and stated
limitations; do not silently carry its claims forward to the current tree.
