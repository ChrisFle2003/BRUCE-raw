# Architecture Decision Records

Hier werden akzeptierte Architekturentscheidungen abgelegt. Jede Entscheidung muss ihren Versions-, Replay-, Sicherheits- und Migrationseinfluss nennen.

Die erste Liste der offenen ADRs steht in [Offene Entscheidungen](../implementation/03-open-decisions.md).

- [ADR-010: Gemeinsamer Forschungs- und Gate-Vertrag](010-research-contract-and-gates.md) – implementiert in Core 0.46; gemeinsame Exact-Validierung, Katalog und Übergangsregeln.

- [ADR-011: Typisierter gemeinsamer Auftragseinstieg](011-typed-application-entry.md) – implementiert in Core 0.47; acht Laufarten mit erhaltenen Fachverträgen.

- [ADR-012: Geprüfte Ausführungsphasen](012-checked-execution-phases.md) – implementiert in Core 0.49; optionale synchrone Ausführung mit Replayprüfung.

- [ADR-013: Menschliche Regelhoheit](013-human-rule-authority.md) – verbindliche Nutzerentscheidung; geschützte Freigabe und Aktivierung noch nicht implementiert.

- [ADR-014: gemeinsamer lokaler Dateiadapter](014-local-file-adapter.md)
