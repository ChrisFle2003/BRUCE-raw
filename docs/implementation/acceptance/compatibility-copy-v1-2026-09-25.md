# Lieferabnahme: Compatibility-Kopierpfad v1

Der `Compatibility`-Payload unterstützt blockweise Records-Kontrollpunkte bis 64 KiB.

- `serialization_control`: bestanden; Bytegleichheit und Blockgrenzen geprüft.
- `session_work_budget_contracts`: bestanden; gemeinsames Budget zählt den neuen Pfad.

Der vollständige M0-/M1-/Gesamtprojektabschluss wird daraus nicht abgeleitet.
