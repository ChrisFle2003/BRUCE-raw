# Lieferabnahme: FractionComparison-Kopierpfad v1

Der `FractionComparison`-Payload unterstützt blockweise Records-Kontrollpunkte.

- `serialization_control`: bestanden; Bytegleichheit und Blockgrenzen geprüft.
- `comparison_replay_control`: bestanden; Replaykontrollen unverändert.
- `session_work_budget_contracts`: bestanden; gemeinsames Budget zählt den Pfad.

Dies ist kein vollständiger M1-/Gesamtprojektabschluss.
