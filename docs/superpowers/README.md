# Planning and specification records

**DOCUMENTED / CONCEPT.** These files preserve design exploration, planning,
and work records. They are not source, test, or runtime evidence and must not
be used to claim that a component is implemented.

Use the [documentation map](../README.md),
[Blueprint](../architecture/03-blueprint-consolidation.md), and
[control and publication contract](../contracts/06-control-and-publication.md)
for the current technical entry points.

Plans and specifications mentioning a semantic index refer to a previous
experiment. Its reversible local archive is `runs/retired-semantic-index/` and
is not an active repository build component. A Cockpit design in this directory
is also **DOCUMENTED / CONCEPT**: the current CMake configuration does not
provide a Cockpit build option or target.
